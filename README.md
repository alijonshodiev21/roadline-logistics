# Roadline Logistics Inc. Website

Stage 1 foundation: React, TypeScript, Vite, Tailwind CSS, Lucide icons, shared layout, design tokens, and the responsive homepage.

## Run locally

```bash
npm install
npm run dev
```

Run `npm run build` to type-check and create the production bundle in `dist/`.

## Brand asset

The header is wired to the official logo at `public/images/roadline-logo.png`. That asset was not present when this stage was created; add the approved original file at that exact path. Until then, the header displays a plain text fallback and does not recreate or alter the logo.
