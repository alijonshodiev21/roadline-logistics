# Roadline Logistics Inc. Website

Stage 1 foundation and homepage, followed by Stage 2 public information pages.

## Run locally

```bash
npm install
npm run dev
```

Run `npm run build` to type-check and create the production bundle in `dist/`.

## Public pages completed

- Home (`/`)
- About (`/about`)
- Services (`/services`)
- Owner-operators (`/owner-operators`)
- Partnerships (`/partnerships`)
- FAQ (`/faq`)
- Contact (`/contact`)
